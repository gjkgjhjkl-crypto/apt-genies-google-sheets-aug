# Apt Genies Google Sheets Connector

## Overview

A lightweight WordPress plugin that allows each logged-in WordPress user to retrieve data from their assigned Google Spreadsheet using Google Apps Script.

## Features

- Multiple spreadsheets per user
- Google Apps Script integration
- Cell retrieval
- Range retrieval
- JSON output
- Image URL output
- Chart data output
- REST API
- AJAX support
- Elementor compatible

## Version

1.0.0
